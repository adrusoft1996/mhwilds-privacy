Who we are

MH Wilds Build Planner (“the App”) is an unofficial fan-made Android application for planning Monster Hunter Wilds builds. It is not affiliated with Capcom Co., Ltd.

Data we do not collect

We do not operate a proprietary analytics/ads backend that collects personal profiles. The App does not require creating an account with us to use the offline catalog, editor, wishlist, or OCR scanner.

Data stored on your device

  • Saved builds, wishlist items, and material inventory (local Room database)
  • App language preference (SharedPreferences)
  • Optional Gemini API key, stored with EncryptedSharedPreferences (AES) on the device and excluded from Android Auto Backup / device transfer

Optional online features

Google Gemini (bring your own API key)

If you enter a Gemini API key in Settings, that key is used only to call Google’s Generative AI APIs for Build Advisor, optional scan refinement, and optional material/farm lookup hints. Requests contain the build/OCR/material context you choose to analyze. Your key and those requests go to Google under Google’s terms. We do not receive or store your API key on our servers.

Community (Firebase)

If you enable Community features, the App may use Firebase Authentication (anonymous and/or Google Sign-In) and Cloud Firestore / Cloud Messaging. That may include a display name, bio, published builds, votes, reports, and push tokens. Processing is performed by Google according to their documentation.

Permissions

  • Internet — Gemini, Community, optional remote images
  • Camera — optional capture for OCR (gallery pick also works)
  • Notifications — optional Community push alerts

Children

The App is not directed at children under 13.

Your choices

  • Clear the Gemini API key anytime in Settings
  • Uninstall the App to remove local databases and preferences
  • Disable Community / notifications in-app or at the system level

Changes

We may update this policy; the “Last updated” date will change. Continued use after changes means you accept the updated policy.

Quiénes somos

MH Wilds Build Planner (“la App”) es una aplicación Android no oficial hecha por fans para planificar builds de Monster Hunter Wilds. No está afiliada a Capcom Co., Ltd.

Datos que no recopilamos

No operamos un backend propio de publicidad/analítica que cree perfiles personales. La App no exige crear una cuenta con nosotros para usar el catálogo offline, el editor, la wishlist o el escáner OCR.

Datos en tu dispositivo

  • Builds guardados, wishlist e inventario de materiales (base Room local)
  • Preferencia de idioma (SharedPreferences)
  • API key opcional de Gemini, guardada con EncryptedSharedPreferences (AES) y excluida de Autorespaldo / transferencia de dispositivo de Android

Funciones online opcionales

Google Gemini (tu propia API key)

Si introduces una API key en Ajustes, solo se usa para llamar a las APIs de IA generativa de Google (Asesor, refinamiento de escaneo, tips de farm). Esas consultas van a Google bajo sus términos. Nosotros no recibimos ni guardamos tu API key en servidores propios.

Comunidad (Firebase)

Si usas Comunidad, pueden emplearse Firebase Auth, Firestore y mensajería (nombre, bio, builds publicados, votos, reportes, tokens push). El tratamiento lo realiza Google según su documentación.

Permisos

  • Internet — Gemini, Comunidad, imágenes remotas opcionales
  • Cámara — captura opcional para OCR (también galería)
  • Notificaciones — avisos opcionales de Comunidad

Menores

La App no está dirigida a menores de 13 años.

Tus opciones

  • Borrar la API key en Ajustes
  • Desinstalar para eliminar datos locales
  • Desactivar Comunidad / notificaciones
